### 🩺 Verdict

The engine work of this phase is sound and the arithmetic holds everywhere I could check it. The 501-to-527 character command descriptions in the tree are not a breach — simulating the packer's `TAIL_OLD`/`TAIL_NEW` rewrite drops all eight of that family under `DESC_LIMIT`, leaving zero over 500 in the archive H9 actually reads.

What fails is the gate coverage, and it fails in the phase's own signature style. 9.0.0 added five documents under `dtd/sigil` and built a subset, an engine and two commands to measure them — but the measuring is structural only, name against token in both directions, and the prose measure was never pointed at the directory. Four of the five documents lose when it is, one of them on a flat banned word at a line I can name. A recognizer that judges every answer, commit message and request body before it lands does not read the 87 KB this release added beside it.

The chain has the same shape of gap one layer down. `link_refusal` declares six ways a link can fail to run and the engine can produce three; the missing three include `artifact-missing`, which is the exact mid-chain failure LAW.CHAIN.5 was written to convert into an up-front refusal. A two-link plan whose hand-off file does not exist — and the directory does not exist — plans clean, `ok=true`, and would discover the absence at link two, which is the outcome the subset opens by declaring it prevents. That is a declared control with no producer, not a bug in a control that fires.

Both are fixable without touching a grammar: add `dtd/sigil` to the two sweep lines, and add an `existsSync` on the hand-off artifact with the refusal the enumeration already carries. Neither changes a declaration, so neither can put the DOCTYPEs and the prose out of step.
