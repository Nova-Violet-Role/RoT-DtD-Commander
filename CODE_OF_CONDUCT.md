# Code of Conduct

**Attacking the claims is the work. Attacking people is not.**

This repository is governed by the organisation's
[Code of Conduct](https://github.com/Nova-Violet-Role/.github/blob/main/CODE_OF_CONDUCT.md),
which applies here in full and is not restated so that it cannot drift.

In this repository specifically:

- Proving that a documented number is wrong, that a control is vacuous, or
  that a `-dtd` answer passes the Adiutor while violating its own law is the
  most welcome contribution there is. Use the "A claim in our docs is false"
  issue form.
- Saying "I could not reproduce this" is a result and is taken seriously.
- Nobody is greyed out. A question the documentation should have answered is
  a defect in the documentation.
- Conduct concerns go to the address in the organisation's Code of Conduct.
