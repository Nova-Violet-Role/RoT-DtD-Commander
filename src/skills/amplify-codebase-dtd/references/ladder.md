# The growth contract

Generated by `node lib/amplify.mjs table` from `dtd/cc-amplify.dtd`. The controls refuse a copy that has drifted from the declarations.

## The ladder

| n | verb | what it means | band |
|---|---|---|---|
| 1 | tweak | one line, one name, one number; nothing that a reader must relearn | amplify |
| 2 | enrich | something true is said in more detail; no behaviour moves | amplify |
| 3 | ameliorate | a rough edge is smoothed where it is felt, in place | amplify |
| 4 | amplification | what exists gains a companion beside it, the original untouched | amplify |
| 5 | magnify | one part is made to carry more of the work it already does | amplify |
| 6 | heighten | a bound is raised or a measure is added to what was unmeasured | enhance |
| 7 | promote | something local becomes shared; a habit becomes a declaration | enhance |
| 8 | cultivate | a pattern is grown across the places that lacked it | enhance |
| 9 | enhancement | a capability the codebase implied is now actually there | enhance |
| 10 | upgrade | a dependency, a contract or a version moves forward under its own gate | enhance |

| 12 | intensification | an existing law is made strict where it was advisory | overhaul |
| 13 | evolve | the shape of a family changes and its members change with it | overhaul |
| 14 | overhaul | an approach is replaced; the old one is removed, not left beside | overhaul |
| 15 | metamorphosis | the codebase becomes a different kind of thing and says so in its major | overhaul |

## The release classes

| class | increment | when |
|---|---|---|
| major | 1.0.0 | a metamorphosis or an overhaul; something the codebase was is no longer |
| mid | 0.1.0 | an elevation, an evolution or an enhancement; a capability that was not there |
| minor | 0.0.1 | a tweak, an enrichment or an amelioration; nothing a reader must relearn |
| alpha | 0.1.0.0 | the shape is settled and the measures are not |
| beta | 0.0.1.0 | the measures hold and the documents do not |
| pre | 0.0.0.1 | everything holds and one thing outside the codebase does not |

## The laws

- **LAW.AMP.1**: A run walks only the layers of AMP.layers its target actually declares, every instrument in the foreground under AMP.ceiling.family seconds and the whole walk under AMP.ceiling.total, with each exit code read directly; a layer that reaches its ceiling is rendered walked timeout, never walked no, because silence must not read as health.
- **LAW.AMP.2**: Instruments before reading: every checker, sweep, audit and control the target already carries is run before a single file is read by hand, and each layer names the instrument it ran and the exit it got; a layer whose findings came from reading alone says so with the instrument attribute empty.
- **LAW.AMP.3**: A possibility of class gap is measured: a declaration exists, the target disagrees with it, and the evidence names the instrument and the path that show it. A possibility of class idea is reasoned or guessed, nothing declares it yet, and its evidence names in adds the law, entity or file it would create; an idea rendered as measured is a failed answer.
- **LAW.AMP.4**: Every possibility carries a verb of the ladder AMP.verb.1 to AMP.verb.15 and a command may expose only the verbs of its own band; a possibility above the band is rendered with the next_verb element naming the number and the command that owns it, never silently kept.
- **LAW.AMP.5**: The generator pages: at most AMP.page possibilities are offered per round, ranked, and the count of the unshown is printed beside them, so an unbounded space is exposed in bounded rounds and the walk may stop as soon as the run stops.
- **LAW.AMP.6**: A run reads the state record at AMP.dir and AMP.state before it exposes anything and writes it after: every possibility keeps a stable id derived from its layer, its files and the law it names, a refused id is never offered again by any later run, and the record carries the families walked, the generator offset, the verb the run ended on and the release badge.
- **LAW.AMP.7**: The study is written before the answer closes: one document per layer walked, one ranked ledger of every possibility of the run, one roadmap ordering the kept ones toward the named release, and one handoff for the next run; every path is printed and every document is UTF-8 with LF endings.
- **LAW.AMP.8**: The release element names the class the kept possibilities amount to by the recognizer (major, mid, minor, alpha, beta or pre), the version it moves from and to, and carries taken no: the command names a release and never takes it, because a version bump is the operator's and this command writes no version anywhere.
- **LAW.AMP.9**: A sample is declared: when a layer holds more files than its ceiling allows, the layer renders read and of with the true numbers and the document says how the sample was chosen; a finding drawn from a sample is never presented as exhaustive.
- **LAW.AMP.10**: The target may be any codebase: when it declares none of the layers, the walk falls back to what is measurable anywhere (the voice of its comments, the guards of its arguments, the ceilings and exit codes of its scripts, its licence headers) and the walk element carries declared no.
